# AI-аудит договора аренды на иврите

Русскоязычный MVP для предварительной проверки текстового договора аренды жилья в Израиле.

## Что делает приложение

1. Пользователь вставляет полный текст договора на иврите.
2. Приложение детерминированно удаляет персональные данные.
3. Обезличенный текст показывается пользователю перед отправкой.
4. Валидатор проверяет, достаточно ли текста договора для AI-анализа.
5. Gemini вызывается через API-ключ закрытого теста, который вводит сам тестировщик.
6. Ответ запрашивается как структурированный JSON по строгой Pydantic-схеме.
7. После ответа выполняется детерминированная проверка цитат: каждый отображаемый риск должен ссылаться на дословную цитату на иврите из обезличенного текста.
8. Отчёт отображается на русском языке.

## Только Gemini

Gemini — единственный поддерживаемый AI-провайдер в активном приложении. Выбора провайдера нет.

- Тестировщик вводит Gemini API-ключ в защищённое поле Streamlit.
- Ключ не коммитится в GitHub и не должен добавляться в код, README или переменные, попадающие в репозиторий.
- Приложение не выводит API-ключ в отчёты или контролируемые ошибки.
- По умолчанию используется модель `gemini-3.5-flash`.
- Advanced override model ID разрешён только для ручного тестирования другой Gemini-модели.

## Важно: текущий MVP только текстовый

Этот MVP принимает готовый текст договора. Он не добавляет и не использует распознавание фото, OCR или обработку изображений в основном сценарии.

## Обезличивание перед Gemini

Перед отправкой в Gemini приложение удаляет типовые персональные данные:

- имена и роли сторон в личных полях;
- израильские ID;
- телефоны;
- email;
- адреса;
- банковские реквизиты.

В Gemini отправляется только обезличенный текст, показанный пользователю в раскрытом блоке перед анализом. Цель продукта — анализировать условия договора, а не личности сторон. Валидатор не требует имён, номеров ID, телефонов, адресов или подписей для признания текста пригодным к AI-анализу.

## Structured Outputs и фактическая корректность

Structured Outputs помогают получить ответ в ожидаемой JSON/Pydantic-форме. Они гарантируют формат данных, но не гарантируют истинность юридических выводов.

Поэтому после Gemini применяется отдельная проверка доказательств на стороне Python:

- цитаты рисков должны дословно существовать в обезличенном источнике;
- неподтверждённые риски удаляются из отображаемого результата;
- неподтверждённые пункты понижаются до `unclear`;
- предупреждения показываются отдельно.

## Юридический дисклеймер

Это прототип для предварительного анализа и подготовки вопросов. Он не является юридической консультацией и не заменяет проверку адвоката, особенно при красных рисках, крупных суммах или нестандартных условиях.

## Настройка и запуск

1. Создать Gemini API-ключ в Google AI Studio.
2. Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

3. Запустить приложение:

```bash
streamlit run app.py
```

4. Открыть приложение в браузере.
5. Вставить Gemini API-ключ в защищённое поле.
6. Вставить полный текст договора на иврите.
7. Нажать **«Обезличить и проверить»**.
8. Проверить обезличенный текст и статус пригодности.
9. Нажать **«Запустить анализ»**.

## Проверки

```bash
python -m py_compile app.py contract_checker/*.py
python -m unittest discover -s tests
```

## Ручной сценарий тестирования

1. Запустить `streamlit run app.py`.
2. Вставить Gemini API-ключ в поле **«Gemini API-ключ — только для закрытого теста»**.
3. Оставить модель по умолчанию `gemini-3.5-flash` или вручную указать другой Gemini model ID в advanced settings.
4. Вставить полный текст договора аренды на иврите.
5. Нажать **«Обезличить и проверить»**.
6. Проверить раскрытый блок с обезличенным текстом.
7. Убедиться, что статус валидации успешный.
8. Нажать **«Запустить анализ»**.
9. Проверить вердикт, красные/жёлтые риски, обычные пункты, неясные фрагменты, вопросы и предлагаемые изменения.
10. Убедиться, что каждый отображаемый риск содержит дословную цитату на иврите.
11. Открыть advanced JSON только при необходимости отладки.
12. Нажать **«Очистить договор и ключ»** после теста.

## Оставшиеся ограничения

- Нет OCR и обработки изображений в текущем MVP.
- Нет реального юридического заключения.
- Детерминированное обезличивание консервативное и может не покрыть все редкие форматы PII.
- Проверка цитат снижает риск неподтверждённых выводов, но не доказывает юридическую правильность интерпретации.
- Качество анализа зависит от полноты вставленного текста и выбранной модели Gemini.
