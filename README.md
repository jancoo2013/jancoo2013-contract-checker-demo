# Проверка договора аренды на иврите — Streamlit демо

Это публичное демо для предварительной проверки текста договора аренды на иврите. Интерфейс сделан на русском языке для русскоговорящих арендаторов в Израиле. Проверка выполняется простыми детерминированными правилами и не использует LLM, платные API, секреты или реальные фотографии договоров.

## Что делает демо сейчас

- Принимает вставленный текст договора на иврите — это основной рабочий режим.
- Принимает OCR JSON с уже распознанным текстом — это мост для будущих OCR-интеграций.
- Принимает JPG/JPEG/PNG изображения только для предпросмотра порядка страниц.
- Не запускает серверный Tesseract OCR в публичном Streamlit-демо.
- Ищет базовые темы договора: стороны, платежи, срок, расторжение, применимое право / юрисдикцию и подписи.
- Отмечает некоторые потенциально опасные формулировки простыми ключевыми словами.
- Показывает краткий отчёт, найденные поля, проверки, зоны для ручной проверки и сырой JSON.
- Экспортирует Markdown-отчёт.

## Текущие рабочие режимы

### 1. Вставить текст договора

Вставь проверенный текст договора во вкладку «Вставить текст договора» и запусти анализ. Этот режим остаётся самым надёжным запасным вариантом, если OCR недоступен или ошибается.

### 2. Загрузить OCR JSON

Если текст уже распознан внешним OCR, можно загрузить JSON с полем `raw_text`, `text` или `pages`. Демо покажет сырой JSON, извлечёт текст, позволит его исправить и запустит тот же детерминированный анализ.

### 3. Загрузить фото договора

Фото-вкладка сохранена, но сейчас работает как предпросмотр загруженных страниц. Она не распознаёт текст на сервере и не запускает долгие OCR-задачи.

Рекомендуемый временный сценарий:

1. распознай текст внешним OCR;
2. вставь текст во вкладку «Вставить текст договора»;
3. проверь отчёт.

## Почему серверный Tesseract отключён

На реальных многостраничных договорах серверный Tesseract в Streamlit Cloud оказался слишком медленным. Даже короткие договоры могут зависать или работать нестабильно, поэтому в публичном демо Tesseract больше не является OCR-путём по умолчанию.

Это изменение делает приложение легче: для запуска больше не требуются `pytesseract`, `opencv-python-headless`, отдельная установка Tesseract или системные языковые пакеты Hebrew/English.

## Следующая OCR-архитектура

Планируемый поток:

```text
Фото → Cloud OCR backend → текст → deterministic validator/report
```

В код добавлен заглушечный адаптер `contract_checker/cloud_ocr.py`. Он описывает будущий интерфейс облачного OCR, но не делает API-вызовы, не содержит ключи и не подключает платные сервисы. Следующий шаг — выбрать провайдера и безопасно подключить его через Streamlit secrets или другой защищённый механизм конфигурации.

## Важные ограничения

Это прототип для предварительной проверки договора. Он не заменяет адвоката. OCR может ошибаться. Рукописный иврит не считается автоматически подтверждённым. Перед подписанием спорного договора проверь опасные пункты вручную или с юристом.

Демо намеренно не содержит:

- реальных фото договоров;
- секретов или API-ключей;
- LLM-вызовов;
- платных API;
- утверждений, что рукописный иврит надёжно распознаётся.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

Рекомендуемые настройки Streamlit Community Cloud:

- Repository: `jancoo2013/jancoo2013-contract-checker-demo`
- Main file path: `app.py`
- Branch: подключённая ветка деплоя

`requirements.txt` должен оставаться лёгким: сейчас для публичного демо нужен только Streamlit. `packages.txt` пустой, потому что системный Tesseract больше не требуется для старта приложения.

После обновления подключённой ветки Streamlit должен автоматически пересобрать приложение.

## Что проверить после redeploy

1. Открыть приложение.
2. Убедиться, что вкладка «Вставить текст договора» анализирует вставленный текст.
3. Убедиться, что вкладка «Загрузить OCR JSON» принимает готовый OCR-результат и запускает анализ.
4. Загрузить тестовое JPG/PNG во вкладке фото и убедиться, что показывается предпросмотр без запуска Tesseract.
5. Убедиться, что юридические и OCR-дисклеймеры остаются видимыми, а рукописный иврит остаётся недоверенным источником.

## English note

This is a Russian-first public Streamlit prototype for deterministic Hebrew lease-contract checks. It is not legal advice. Server-side Tesseract is disabled in the public demo; image upload currently provides preview only, OCR JSON remains supported for future cloud OCR results, and handwritten Hebrew is not trusted as verified text.
