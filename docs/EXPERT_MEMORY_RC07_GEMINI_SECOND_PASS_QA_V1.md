Источник для сверки — только печатные пункты обезличенного RC07, уже описанные в [исследовательском пакете](../research/question_engine/expert_memory/rc07_printed_mechanisms_v1.json). Владелец передал в беседе ответы первого и второго проходов из отдельного чата Gemini. Полный промпт, точная версия модели и параметры вызова в репозитории не сохранены; оригинальные страницы, OCR, рукопись, подписи и реквизиты сюда не добавляются. Это наблюдение за присланным ответом, а не независимая оценка точности модели, подтверждение исполнения договора или правовой вывод.

Это **кандидаты на проверки полноты**, а не подсчёт ошибок: формат задания и полнота входа второго прохода не архивированы настолько, чтобы считать пропуски независимым измерением recall.

## Формулировки для следующего диагностического промпта

1. Пример JSON должен использовать условные идентификаторы, которых нет в договоре; не подсказывать настоящую пару пунктов в образце ответа.
2. Для каждой связи отдельно описывать напечатанное условие, предполагаемое следствие и факты или документы, без которых следствие не установлено. Поле `must_distinguish` не должно представлять такое следствие как уже состоявшееся.
3. Для каждого срока связывать **участника → действие (отправить / доставить / исправить / вернуть) → событие отсчёта → период → целевой пункт или инструмент**. Правило предполагаемой доставки само по себе не переписывает срок отправки.
4. При замене арендатора различать предложение кандидата, согласование, принятие обязательств, фактическую замену и прекращение обязательств прежней стороны. При обеспечении сохранять отдельный экземпляр и собственное условие возврата.

Новые семейства Router и вопросы в [текущем инвентаре](../contract_checker/question_engine/inventory.py) этим наблюдением не обоснованы: `DAMAGE`, `NOTICE`, `SECURITY`, `EARLY_EXIT` и вопросы об освобождении, цене продления и внешнем документе уже существуют. Рабочее `DOCUMENT_REFERENCE` остаётся кандидатом исследовательского глоссария. Пакет RC07 от 01.10 сохраняет исторический статус гипотез до теста; данный файл отдельно фиксирует присланное наблюдение. Дальнейшие внешние прогоны реального договора, Gold, training, runtime и независимый cohort scoring этим PR не разрешаются.
