Это обозначение модели сообщено владельцем, не подтверждено машинным журналом вызова; параметры и полные неизменённые транскрипты ответов в репозитории не хранятся. Следствие для метода: модельные ивритские цитаты — **candidate transcription**, а не проверенные исходные опоры. Сначала отдельно проверяются источник, страница/пункт и материальные цифры/условия; лишь затем Router и связи. Для каждой ошибки фиксируется стадия (вход/чтение, маршрутизация, связь, правовой вывод); без изолированного сравнения причина остаётся неизвестной.

Эти ответы нельзя считать независимым benchmark, доказательством неспособности всех бесплатных моделей, источником Gold, обучающими примерами или поводом переписать запечатанный синтетический эталон. Ни один модельный ответ из этого наблюдения не добавлен в корпус меток.
